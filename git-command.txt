1. Git Configuration Commands

These commands configure your Git username and email.

No.	Command	Short Use
1	git --version	Check the installed Git version.
2	git config --global user.name "Rohit"	Set your Git username.
3	git config --global user.email "your@email.com"	Set your Git email.
4	git config --list	Display Git configuration settings.
5	git config user.name	Check your configured username.
6	git config user.email	Check your configured email.
7	git config --global --unset user.name	Remove your global username setting.
8	git config --global --unset user.email	Remove your global email setting.

No.	Command	Short Use

Remember:

git add = Prepare changes.
git commit = Save changes in local Git history.
git push = Upload commits to a remote repository.

8. Git Undo and Reset Commands

These commands help you undo changes. Use caution: some commands can permanently discard work.

No.	Command	Short Use
83	git restore filename	Discard unstaged changes in a file.
84	git restore .	Discard unstaged changes in tracked files in the current directory.
85	git restore --staged filename	Unstage a file without discarding its changes.
86	git reset --soft HEAD~1	Undo the latest commit while keeping changes staged.
87	git reset --mixed HEAD~1	Undo the latest commit while keeping changes in the working tree unstaged.
88	git reset --hard HEAD~1	Move HEAD back one commit and discard affected tracked changes.
89	git revert <commit-id>	Create a new commit that reverses a specified commit.
90	git clean -n	Preview untracked files that would be removed.
91	git clean -f	Remove untracked files.
92	git clean -fd	Remove untracked files and directories.

Important difference:

git reset changes the current branch's history.
git revert creates a new commit to reverse an earlier commit.
git restore restores file contents or staging state.
git clean removes untracked files.

Do not use git reset --hard or git clean -fd unless you are certain you do not need the affected work.

11. Git .gitignore Commands

A .gitignore file specifies untracked files that Git should ignore.

There is no dedicated git ignore command built into Git. You create and edit the .gitignore file yourself.

Create a .gitignore file in Linux:

touch .gitignore

Example .gitignore contents:

node_modules/
.env
*.log
.terraform/
terraform.tfstate
No.	Command or Entry	Short Use
110	touch .gitignore	Create a .gitignore file on Linux.
111	git status --ignored	Show ignored files as well as ordinary status information.
112	git check-ignore filename	Check whether a file is ignored.
113	node_modules/	Ignore a directory named node_modules.
114	.env	Ignore a file named .env in matching locations.
115	*.log	Ignore files ending in .log.

Important: Adding an already tracked file to .gitignore does not stop Git from tracking it. For example, to stop tracking .env while retaining the local file, use:

git rm --cached .env
git commit -m "Stop tracking env file"

Never upload passwords, API keys, AWS credentials, or other secrets to GitHub.
